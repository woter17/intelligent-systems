# Интеллектуальные системы

Практические работы Алексеева Николая, группа ИТ 15-16.

- **МО** — шесть ноутбуков по классификации, регрессии и оптимизации моделей; данные, сохранённые модели, результаты и графики.
- **ИКМ** — классификация видов ирисов с интерфейсом Gradio, обучением модели и тестами; отчёт и презентация. Инструкции: [ИКМ/README.md](ИКМ/README.md).
- **ЭС** — учебная экспертная система по симптомам простудных заболеваний, сценарии и тесты; отчёт и презентация.

## Установка

Нужен Python 3.10.

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

На Windows активация: `.venv\Scripts\activate`.

## Запуск

Все шесть практик МО:

```bash
python МО/run_all.py
```

Просмотр ноутбуков:

```bash
python -m jupyterlab МО
```

Интерфейс ИКМ:

```bash
cd ИКМ
python app.py
```

Экспертная система из корня репозитория:

```bash
python ЭС/expert_system.py
python ЭС/expert_system.py --scenario orvi
```

Работы МО выполнять по порядку: 1 → 2, 3 → 4, 5 → 6. Сохранённые результаты уже включены в ноутбуки.
