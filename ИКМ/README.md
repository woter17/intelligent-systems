# Учебный помощник для определения вида ириса

Алексеев Николай, ИТ 15-16. Практики ИКМ 7–11. Тема C.3: классификация видов ирисов.

## Задача и пользователь

Я определяю Setosa, Versicolor или Virginica по четырём размерам цветка. Целевой пользователь — учащийся, знакомящийся с классификацией растений и машинным обучением. Пользователь вводит измерения в сантиметрах, нажимает кнопку и получает предполагаемый вид. Образовательное применение связано с понятным показом данных, модели и её ошибок.

## Данные

Локальный файл `data/iris.csv` содержит 150 строк, по 50 на вид, четыре числовых признака и столбец `species`. Пропусков нет. Порядок признаков: `sepal_length`, `sepal_width`, `petal_length`, `petal_width` — длина/ширина чашелистика, затем длина/ширина лепестка. Все размеры в сантиметрах.

Источник: [UCI, Iris Dataset](https://archive.ics.uci.edu/dataset/53/iris), R. A. Fisher, DOI 10.24432/C56C76, лицензия CC BY 4.0. CSV подготовлен из [встроенной копии scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html). Во время обычного запуска скачивать данные не нужно.

Проверено на Python 3.10.20. Открыть Terminal в этой папке.

```bash

source .venv/bin/activate
python -m pip install -r requirements.txt

```


## Как устроен код

| Файл | Назначение |
|---|---|
| baseline.py | Собственное правило: ближайшая средняя длина лепестка по классу |
| train.py | CSV, X/y, разбиение, CV двух подходов, ошибки, окончательное обучение и сохранение |
| predict.py | Загрузка Pipeline, проверка четырёх значений, предсказание и текст ответа |
| app.py | Четыре поля Gradio и кнопка вызова prediction_text |
| models/iris_model.pkl | Модель, масштабирование, порядок признаков и сведения о train |
| tests/test_basic.py | Функция, формат, реальный запуск веб-приложения и ошибочный ввод |
| reports | Таблицы CV, ошибки CV и итоговый JSON |
| figures | Графики и снимок работающего интерфейса |
| Отчёт_ИКМ.docx | Отдельный отчёт по практикам 7–11: данные, модели, результаты, интерфейс и тесты |

Названия видов кодируются числами 0, 1, 2. Числовые признаки масштабируются `StandardScaler` внутри `Pipeline`. Подготовка обучается только на тренировочной части каждого блока. [Объяснение утечки данных в scikit-learn](https://scikit-learn.org/stable/common_pitfalls.html).

## Обучение и результаты

```bash
python train.py
```

Разбиение: 120 объектов train/CV и 30 объектов итогового test, stratify, random_state=42. Пять блоков CV применяются только к train. Собственное правило использует один признак и изучает средние на train; логистическая регрессия использует все четыре признака. Основная метрика — macro-F1, дополнительная — accuracy; показывается стандартное отклонение F1 между блоками.

| Подход | Средний macro-F1 CV | SD CV |
|---|---:|---:|
| Правило по длине лепестка | 0,950 | 0,017 |
| Логистическая регрессия | 0,958 | 0,027 |

Я выбрал логистическую регрессию по большему среднему F1; при равном среднем критерием был бы меньший SD. Оба разброса невелики, но правило стабильнее по этому показателю. Поэтому результат не доказывает абсолютного превосходства регрессии. После выбора итоговая модель обучена на 120 объектах и проверена на test один раз в конце процедуры отбора.

Результат test: 28 из 30 верно, accuracy = 0,933, macro-F1 = 0,933. Для Setosa precision/recall равны 1,0; для Versicolor и Virginica — 0,9. Один Versicolor перепутан с Virginica и один Virginica с Versicolor. На CV пять ошибок, чаще истинный вид Virginica определяется как Versicolor. Подробности находятся в `reports/summary.json`, `cv_errors.csv` и матрицах ошибок.

Повторный запуск train.py воспроизводит тот же эксперимент. Я не подбираю параметры по итоговому тесту.

## Тесты

```bash
python -m pytest tests -q
```

Проходят шесть проверок с учётом трёх параметризованных ошибок ввода. Тест запуска Gradio поднимает настоящий локальный сервер на свободном порту и получает предсказание через API `/predict`.

## Два примера для живого показа

Порядок полей всегда один: длина чашелистика; ширина чашелистика; длина лепестка; ширина лепестка.

1. `4.4; 3.0; 1.3; 0.2` — истинный вид Setosa, ответ Setosa.
2. `6.1; 2.6; 5.6; 1.4` — истинный вид Virginica, ответ Versicolor. Это реальная ошибка на пограничном тестовом примере. Её нужно объяснить, а не выдавать за верный результат.

Десятичный разделитель в Python — точка. В интерфейсе лучше вводить значения с точкой. Отрицательные/пустые/бесконечные значения отклоняются. Выход за диапазон train сопровождается предупреждением в ответе.

## Ограничения и защита

Модель знает только три вида из Iris. Она не распознаёт фотографию и не проверяет, что пользователь измерил именно ирис. Тест из 30 объектов даёт приблизительную оценку. Все файлы модели обучены в scikit-learn 1.7.2; использовать указанные версии зависимостей.

Для защиты: `Отчёт_ИКМ.docx`, `Презентация_ИКМ.pptx`, отдельный `Текст_выступления.txt`. Отчёт содержит 10 страниц с пояснениями, фактическими метриками и снимками двух примеров. Семь слайдов соответствуют структуре практики 11.
